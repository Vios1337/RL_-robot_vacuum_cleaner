# Обучение робота-пылесоса

Робот-пылесос учится собирать мусор в комнате с помощью Q-learning. Среда написана на Gymnasium: комната размером 8×8, четыре кучки мусора и клетка с котом, на которую нельзя заезжать.

За один эпизод нужно собрать весь мусор за 100 шагов. При столкновении с котом эпизод заканчивается.

## Обучение

Состояние агента включает координаты робота и наличие мусора в каждой из четырёх точек. Доступны четыре действия: вверх, вниз, влево и вправо.

Награда:

- −1 за каждый шаг;
- +50 за собранную кучку мусора;
- +100 дополнительно за завершение уборки;
- −150 за столкновение с котом.

Агент обучается 10 000 эпизодов. Для выбора действий используется ε-жадная стратегия с постепенным уменьшением вероятности случайного действия.

## Результат

В сохранённом запуске после обучения агент успешно завершил 200 из 200 тестовых эпизодов. Средняя длина уборки — 15 шагов. Базовый агент, который всегда движется вниз, не завершил ни одной уборки.

В ноутбуке также есть анимация движения робота.

## Запуск

Откройте [RL_пылесос.ipynb](RL_пылесос.ipynb) в Google Colab или Jupyter и выполните все ячейки по порядку.

Для локального запуска:

```bash
pip install -r requirements.txt
jupyter lab
```

Для анимации через `to_html5_video()` нужен FFmpeg. Если он не установлен, замените `anim.to_html5_video()` на `anim.to_jshtml()` в функции `show_animation`.
